# Prints

Capturas de tela usadas na documentação e na apresentação:

- Remix: contrato compilado e deploy pela MetaMask
- MetaMask: confirmação de uma transação com ETH (pagamento do prêmio ou depósito)
- Etherscan: página do contrato e código verificado
- dApp: tela da seguradora, tela do segurado, um erro tratado e o histórico de eventos
